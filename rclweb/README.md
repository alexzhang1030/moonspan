# rclweb

Rust core for [rclweb](https://github.com/alexzhang1030/rclweb): R2WP
protocol codecs, CDR, and deterministic session/channel state. The same
crate links into [`rclwebd`](https://crates.io/crates/rclwebd) natively
and compiles to `wasm32-unknown-unknown` for the browser package
[`rcl-web`](https://www.npmjs.com/package/rcl-web).

Application API: [`docs/runtime/core.md`](../docs/runtime/core.md).
